# Tour Operator — Quick start

**Who this is for:** Tour companies, DMCs, and **self-employed guides who own their own tours**.  
**Login:** `https://[your-site]/guide/login`  
**Time to complete:** ~20 minutes first time

---

## What you do on Pagoda

1. Publish **your** guide profile (public link for agents).
2. Add **team guides** (optional) and send invites.
3. Upload tours in **Tour Library** and link guides to tours.
4. Respond to **job offers** from travel agents.

---

## Step 1 — Log in

1. Open **Guide login**.
2. Enter email and password.

## Step 2 — Complete your own guide profile

1. Go to **Settings** → **Profile**.
2. Fill in **Guide profile** (one form): photo, bio, languages, destinations, experience, certification text, video-call yes/no, availability calendar.
3. Click **Save guide profile**.
4. When **Profile completeness** is 100%, click **Publish profile**.
5. Copy your **public link** (`/g/g-xxxxxxxx`) and test in a private browser window.

## Step 3 — Add a tour to the library

1. Open **Tour Library** from the menu or landing page.
2. Click **Add tour** (or equivalent create button).
3. Fill tour details and **upload at least one image**.
4. Set pricing and **publish** the tour (status: published).

> 📷 **Screenshot:** Create tour form with image upload

## Step 4 — Link yourself (or a guide) to a tour

Agents only see guides that are **assigned** to a tour.

1. From **Tour Library**, open **Tour assignments**  
   (or go to `https://[your-site]/guide/guide-tour-assignments`).
2. **By tour:** select a tour → tick the guide(s) → **Save**.  
   **Or by guide:** select a guide → tick tours → **Save**.
3. To show **yourself** on a tour: assign **your** operator profile to that tour.

> 📷 **Screenshot:** Tour assignments screen (tour selected, guides ticked)

## Step 5 — Add a team guide (optional)

Skip this if you work alone.

1. Open **My Guides** → **Add guide**.
2. Fill the profile form → **Create guide** (draft).
3. Click **Send invite** → enter the guide’s email → send link.
4. When they finish the invite, review and **Publish** their profile.
5. Use **Tour assignments** to link them to tours.

> 📷 **Screenshot:** My Guides list with Send invite / Publish  
> _Save as: `operator-07-my-guides.png`_

## Step 6 — Respond to jobs

1. Open **Landing** / job list (your guide dashboard).
2. Open a job → submit a bid or message in the conversation.
3. Complete tours through the normal itinerary / hire flow.

## Quick reference

| Task | Where |
|------|--------|
| My public profile | Settings → Guide profile → Publish |
| Team guides | My Guides |
| Tours | Tour Library |
| Link guide ↔ tour | Tour assignments |
| Share profile | Copy link after publish |

---

## Common issues

| Problem | Fix |
|---------|-----|
| Only **Settings** visible | Account pending approval — contact Pagoda admin |
| Public link does not open | Profile must be **published** and completeness 100% |
| Agent does not see me on a tour | Tour must be **published** and you must be in **Tour assignments** |
| Photo does not show after upload | Click **Save guide profile** after upload; refresh page |
