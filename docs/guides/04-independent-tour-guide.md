# Independent Tour Guide — Quick start

**Who this is for:** A **self-employed** guide who wants to **respond to job offers** and build a profile — but does **not** run a tour company or manage a team.

---

## Important: signup today

| Your situation | What to do |
|----------------|------------|
| You own your tours and want Tour Library + public profile + job bids | Register as **Tour operator** → use [01 — Tour operator](./01-tour-operator.md) |
| You only want the job board (no My Guides, no tour upload) | **Contact Pagoda** — we create an **Independent guide** account (`is_operator: false`) |

**You do not need a new “role” in the app** if you are happy registering as Tour operator. That is the correct path for most self-employed guides with their own tours.

---

## What an Independent guide account can do (when Pagoda sets it up)

1. Log in at **Guide login**.
2. Complete **Settings** → **Guide profile** and publish public link.
3. View **jobs** on the guide landing / job board and **submit bids**.
4. Message agents in **conversations** after a job connection.

---

## What Independent guides cannot do (by design today)

| Cannot do | Who does it instead |
|-----------|---------------------|
| **My Guides** / manage a team | Tour operator |
| Upload tours to **Tour Library** | Tour operator (or register as operator) |
| **Link yourself to a tour** for agents to see on that tour | Tour operator uses **Tour assignments** |
| Change **certification badge** (Provisional / Certified / Elite) | Pagoda admin |

These items are **product rules today**, not missing documentation. If self-linking or self-service certification is required globally, that is a **future product change**.
