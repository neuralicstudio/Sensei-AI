# Travel Agent — Quick start

**Who this is for:** Travel advisors booking tours and guides for clients.  
**Login:** `https://[your-site]/agent/login`

---

## What you do on Pagoda

1. Browse **Tour Library** (tours from operators/guides).
2. **Find guides** by name and open public profiles.
3. Build **itineraries**, add jobs, hire guides, export **PDF** for clients.
4. Message guides in **conversations** (via jobs / itinerary — direct “Contact guide” from profile coming later).

---

## Step 1 — Log in

1. Open **Agent login**.
2. Enter email and password.
3. Full menu appears after Pagoda **approves** your account (if you only see Settings, contact Pagoda).

## Step 2 — Browse Tour Library

1. Open **Tour Library** from the menu.
2. Search or filter by location / activity type.
3. Open a tour to see details, **images**, and **Available guides** (guides the operator assigned to that tour).

## Step 3 — Find a guide by name

1. Open **Find Guide**.
2. Type at least 2 letters of the guide’s name.
3. Click **View profile** → public page `/g/...` (only **published** profiles).

> 📷 **Screenshot:** Find Guide search results  
> _Save as: `agent-04-find-guide.png`_

---

## Step 4 — Build an itinerary and add a tour

1. Create or open an **Itinerary**.
2. **Add activity** → **Select from Library** (or Add Job).
3. Pick tour, dates, participants.
4. Guides can **bid**; you hire from the conversation / hire flow.

> 📷 **Screenshot:** Itinerary with activity from tour library  
> _Save as: `agent-05-itinerary.png`_

---

## Step 5 — Export PDF for your client

1. Open the itinerary → **Export PDF** (or print flow).
2. Check that tour **images** and details appear.
3. Send PDF to your client.

> 📷 **Screenshot:** PDF preview with tour image

## Quick reference

| Task | Where |
|------|--------|
| See guides on a tour | Tour Library → open tour → Available guides |
| Search by guide name | Find Guide |
| Public profile | `/g/slug` from search or tour |
| Message a guide | Job / itinerary conversation (not profile button yet) |

---

## Common issues

| Problem | Fix |
|---------|-----|
| Only **Settings** visible | Account needs admin **approval** |
| No guides on a tour | Operator must **publish** tour and set **Tour assignments** |
| Tour images missing | Report to Pagoda with tour name; refresh after platform update |
| Profile link 404 | Guide profile not **published** yet |
